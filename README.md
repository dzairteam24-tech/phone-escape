# 📱 هروب الهاتف — +1 Charge: Phone Escape

لعبة Roblox كاملة: أفاتار صغير محبوس داخل هاتف عملاق. كل أيقونة تخطو عليها = ‎+1 شحن ⚡‎، والمراحل تعيش **داخل التطبيقات**، ومراحل الزعماء تعمل على **بطارية نازفة** — اهرب قبل أن تصل إلى ‎0%‎.

الأرقام كلها من بحث اللعبة الأصلية ‎+1 Speed Keyboard Escape‎ (بوابات بالـLevel، جداول Wins، سلالم المضاعفات، الترقية، تحديث النظام) — التصميم الكامل في وثيقة التصميم المرافقة للمشروع.

## التشغيل الفوري
1. افتح **PhoneEscape.rbxl** في Roblox Studio.
2. اضغط **Play**. هذا كل شيء — الخريطة مبنية داخل الملف، والحفظ في Studio تجريبي (يُحفظ فعليًا عند النشر).

## ما بداخلها (v1)
- **اللوبي = شاشة رئيسية:** 432 أيقونة ملونة بوجوه تطبيقات، كلها تعطي ‎+1⚡‎ وتومض عند الخطو.
- **8 محطات شحن** (USB ← مولّد الطوارئ)، تُشترى وتُرقّى 8 مرات بالـWins فقط، وكوابل Robux اختيارية (‎×3/×9/×25/×100‎ على إنتاج المحطات فقط).
- **العالم 1 كامل — 15 مرحلة** داخل الإعدادات والمعرض والفيديو، بـ9 ميكانيكيات (متحركة، مختفية، نطاطة، كاسحات = مؤشرات تحميل، أحزمة سكرول، أبراج، مسارات مزدوجة بنجوم ⭐، نقاط حفظ)، وبوابات Level كما في البحث (المرحلة 10 = 70، الأخيرة = 120)، وجوائز Wins الموثقة (1 ← 150K).
- **🔋 ميكانيكية البطارية:** مراحل الزعماء (5/10/15) تبدأ بـ100% وتنزف ‎1.1%/ثا‎؛ خلايا 🔋 على الطريق ‎+10%‎؛ صفر% = عودة لنقطة الحفظ. شريط بطارية يظهر في الواجهة أثناء الجولة.
- **متاجر:** 11 غطاءً مضيئًا (حتى اللانهاية ‎×5,000,000‎)، 11 هالة إشارة (حتى ‎×10‎)، 7 أدوات ‎+%‎ تُجمع، 17 وصلة شحن سريع (حتى ‎+500M/خطوة بـ 7.5T‎).
- **ترقية الهاتف:** 32 موديلًا من «هاتف الطوب» ‎×1.5‎ حتى القمة (الأولى 20 موثقة، والباقي امتداد بنفس النمط) — **تحديث النظام:** 32 ترقية + ‎200T Wins ← ‎×8‎ دائم.
- **أنظمة يومية:** مكافأة دخول بسلسلة، 3 مهام يومية، عجلة كل 12 ساعة، أرباح أثناء الغياب (50% حتى 8 ساعات)، هدية كل 5 دقائق، أكواد: ‎LAUNCH‎ / ‎PHONE‎ / ‎BATTERY‎.
- **لوحتا صدارة** TOP LEVEL وTOP WINS، حفظ بيانات آمن (قراءة فاشلة = إعادة محاولة، لا تصفير).
- **العالم 2 (التطبيقات الاجتماعية):** أرقامه جاهزة في Config وبوابته معلنة «قريبًا» في اللوبي — يُبنى في التحديث الأول.

## قبل النشر (مرة واحدة، ~10 دقائق)
1. أنشئ الباسات العشرة في Creator Hub بالأسعار المقترحة في ‎Config.PASSES‎ (تعليقات الأسطر): DoubleCharge ‏99، DoubleWins ‏95، VIP ‏399، غطاء المجرة ‏389، غطاء اللانهاية ‏1,799، إشارة الظلام ‏739، والكوابل ‏79/345/749/1,199.
2. أنشئ المنتجات الأربعة (SkipStage ‏49، وحزم الشحن ‏99/399/1,499) والصق كل ID في ‎Config.PASSES‎ / ‎Config.PRODUCTS‎ مكان الصفر.
3. Studio ← Game Settings ← Security ← فعّل **Studio Access to API Services**، وانشر اللعبة **Public**.
