# 📱 هروب الهاتف — +1 Charge: Phone Escape

لعبة Roblox بتصميم جديد كليًا **«مدينة الدوائر»**: أنت شخصية صغيرة داخل
هاتف عملاق — لوحة أمّ ليلية مضيئة بالنيون. اركض في الشوارع واخطُ على عقد
الشحن ⚡، تدرّب في حيّ الشحن، واصعد **أبراج الشرائح الـ15** للهروب قبل أن
تفرغ البطارية!

## التشغيل
افتح `PhoneEscape.rbxl` في Roblox Studio واضغط **Play**.

## كيف تلعب
- **شوارع المدينة:** كل خطوة على عقدة شحن مضيئة = +1 شحن (تزيدها «وصلات
  الشحن السريع» حتى +500M/خطوة).
- كلما زاد شحنك زادت **سرعتك** و**مستواك** (Level) — والأبراج تُفتح بالمستوى.
- **الأبراج الـ15** في شمال المدينة: اخطُ على وسادة ENTER لتدخل، واصعد
  المسار داخل البرج حتى القمة 🏁 — جوائز Wins تُنفق على الأغطية المضيئة 📦
  وهالات الإشارة 📶 والأدوات 🎒.
- **مراحل الزعماء (5، 10، 15) 🔋:** بطاريتك تفرغ أثناء الجولة! التقط خلايا
  🔋‏ (+10%) ولا تدعها تصل 0% وإلا عدت لنقطة الحفظ.
- **محطات الشحن 🔌:** 8 محطات تُفتح وتُرقّى 8 مرات بالـWins؛ الكوابل
  (Robux) تضاعف إنتاجها ×3/×9/×25/×100.
- **ترقية الهاتف 📱:** 32 موديلًا من «هاتف الطوب» إلى «هاتف الخلق» — كل
  ترقية تصفّر الشحن وتضاعف كسبك (حتى ×1e23).
- **تحديث النظام 🔄:** بعد 32 ترقية + 200T Wins = ×8 دائم (قابل للتكرار).
- **يوميًا:** سلسلة دخول، 3 مهام، هدية كل 5 دقائق، عجلة حظ كل 12 ساعة،
  أرباح غياب 50% حتى 8 ساعات، أكواد: `LAUNCH` / `PHONE` / `BATTERY`.

## النشر (خطواتك، ~10 دقائق)
1. افتح اللعبة في Studio ← **Game Settings ← Monetization** وأنشئ الباسات
   العشرة والمنتجات الأربعة بالأسعار المقترحة في `src/shared/Config.luau`
   (قسم PASSES / PRODUCTS).
2. الصق كل ID في مكانه في `src/shared/Config.luau` (القيم الآن 0).
3. فعّل **Studio API Access** من Game Settings ← Security.
4. **File ← Publish to Roblox** واجعلها Public.
5. (اختياري للمطورين) المشروع Rojo: `rojo build default.project.json`.

الأرقام كلها (بوابات المستوى، جداول Wins، الأغطية ×5,000,000، سلّم
الترقيات...) من بحث موثّق عن اللعبة الأصلية +1 Speed Keyboard Escape —
انظر وثيقة التصميم `تصميم-هروب-الهاتف.md`.

الكود: `src/shared` (الأرقام والرياضيات)، `src/server` (البيانات، بناء
العالم، اللعب، المتجر)، `src/client` (الواجهة). الاختبارات: `tests/`.
